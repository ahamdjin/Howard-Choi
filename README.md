# Law Firm Website

A React, TypeScript, and Vite project prepared as the foundation for a law firm website.

## Development

You need Node.js and npm. Node.js can be installed with [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone https://github.com/ahamdjin/Howard-Choi.git
cd Howard-Choi
npm install
cp .env.example .env
npm run dev
```

Replace the placeholder values in `.env` with the client credentials for your Supabase project.

## Commands

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` checks the codebase with ESLint.
